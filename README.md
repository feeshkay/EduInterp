# 🧵 CraftBase Pro — Your Free Local Studio Manager

A complete craft business manager that runs entirely in your browser. No subscription, no account, no cloud. Everything saves locally on your device.

---

## ✨ What's Included

| Section | What it does |
|---|---|
| **Dashboard** | Revenue, profit, low stock alerts, machine depreciation |
| **Materials** | Track supplies with costs, stock levels, and where to buy them |
| **Products** | Catalog with photos, craft type, platform, and margin tracking |
| **Recipes** | Link materials + labour + machine to each product for true COGS |
| **Processes** | Step-by-step how-to guides for each craft |
| **Time Tracker** | Timer + item counter per crafting session |
| **Orders** | Sales across Etsy, Shopify, in-person, etc. |
| **Expenses** | Business costs with tax deductible flagging |
| **Machines** | Glowforge, Cricut, etc. — depreciation + per-use cost |
| **Pricing Helper** | Suggested prices by craft type (Glowforge, Cricut, crochet, gelli print…) |
| **Tax** | Estimates for quarterly payments, SE tax, deductions |
| **Reports** | P&L, monthly revenue, expense breakdown |
| **Craft Space** | Map your room, shelves, and storage |
| **Efficiency Tips** | Craft-specific tips for Glowforge, Cricut, embroidery, crochet, gelli printing |
| **Import / Export** | CSV exports, full JSON backup and restore |

## 🚀 How to Use on GitHub Pages (Free Hosting)

1. **Create a free account** at [github.com](https://github.com) if you don't have one

2. **Create a new repository**
   - Click the **+** icon (top right) → **New repository**
   - Name it `craftbase`
   - Set to **Public**
   - Check **"Add a README file"**
   - Click **Create repository**

3. **Upload the file**
   - Click **"Add file"** → **"Upload files"**
   - Drag and drop `index.html` from your downloads
   - In the commit box at the bottom, click **"Commit changes"**

4. **Enable GitHub Pages**
   - Go to **Settings** → **Pages** (left sidebar)
   - Under **"Source"** select **"Deploy from a branch"**
   - Choose **main** branch and **/ (root)**
   - Click **Save**
   - Wait 2–3 minutes

5. **Your URL** will be:
   ```
   https://yourusername.github.io/craftbase
   ```
   Bookmark this in every browser you use!

## 💾 About Your Data

- **Everything is stored in your browser's localStorage** — no server, no cloud
- Data lives in **this browser on this device only**
- Clearing browser cache/history will delete your data
- **Export a JSON backup regularly** (Import/Export → Full Backup)
- To use on another device: export JSON backup → open the app on new device → import the JSON

---

## 🔄 Updating the App

When a new version of CraftBase is available:
1. Download the new `index.html`
2. Go to your GitHub repository
3. Click on `index.html` → click the pencil (edit) icon → paste new content
4. OR: Delete the old file and upload the new one
5. Your data is safe in localStorage — updates don't delete it
