How to Use CraftBase Pro

🚀 Getting Started
1
Add your materials — Go to Materials and add everything you use. Set cost per unit, current stock, and where you buy it. This powers all your profit calculations.
2
Add your products — Everything you sell goes here with a photo, price, and craft type. This is your catalog.
3
Create Recipes — Link materials + labour to each product. CraftBase calculates your exact COGS and tells you if your price is profitable.
4
Write Processes — Step-by-step guides for how you make each thing. Great reference and helps calculate accurate time.
5
Use the Timer — Hit Start when you begin crafting. Stop when done. It logs how long things take and how many you made.
6
Add machines — Log your Glowforge, Cricut, etc. with purchase price and lifespan. CraftBase calculates monthly depreciation and per-use cost automatically.
7
Use Pricing Helper — Enter your craft type and costs to get a suggested retail price that covers everything including machine use.
8
Map your Craft Space — Set room dimensions, add shelves, and get organization suggestions.
9
Export backups regularly — Go to Import/Export and save a JSON backup. Keep it in Google Drive or email it to yourself.
🌐 Free Hosting with GitHub Pages
1
Create a free account at github.com if you don't have one.
2
Create a new repository — Click the + icon → New repository. Name it craftbase. Set it to Public. Check "Add a README file". Click Create.
3
Upload this file — Click "Add file" → "Upload files". Drag and drop the craftbase_pro.html file you downloaded. Rename it to index.html in the commit box.
4
Enable Pages — Go to Settings → Pages. Under "Source" select "Deploy from a branch". Choose "main" branch and / (root). Save.
5
Your URL will be: yourusername.github.io/craftbase — visit it in any browser and bookmark it!
6
Important — Data is stored in that browser on that device. Use Import/Export to move data between devices. Export JSON backups often.
⚠️ Data Note If you clear your browser cache or history, your data will be lost. Always keep a recent JSON backup!
