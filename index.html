Privacy
🔒
All data is stored locally in your browser by default. Nothing leaves your device unless you turn on Cloud Sync in Data Management and tap Push or Pull.
Data Management
Export regularly to back up your vocabulary, logs, and materials. Vocab/logs/documents are stored in localStorage, and file attachments are stored separately in IndexedDB (much more room — typically hundreds of MB or more). Both are browser-local — clearing browser data will erase them unless exported, and the JSON export below includes attachments too. The IEP Summary export produces a plain-text file safe to share with a case manager (no student names included unless you added them).
☁️ Cloud Sync (GitHub Gist)
Sync your data between devices using a private GitHub Gist — only you can see it. Your token stays saved on this device only and is never included in exports or the Gist itself. Note: file attachments are not included in Cloud Sync (only their names) — use the JSON export/import above to move attachments between devices. Needs a token with gist access (classic token with the "gist" scope, or a fine-grained token with "Gists: read and write").
App Info
App: EduInterp v1.0
Storage: Browser localStorage (data) + IndexedDB (attachments), plus an optional private GitHub Gist if you turn on Cloud Sync above
Purpose: Personal educational interpreting professional log
