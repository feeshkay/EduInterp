Privacy
🔒
All data is stored locally in your browser by default. Nothing leaves your device unless you turn on Cloud Sync in Data Management and tap Push or Pull.
Data Management
Export regularly to back up your vocabulary, logs, and materials. Data is stored in localStorage — clearing browser data will erase it unless exported. The IEP Summary export produces a plain-text file safe to share with a case manager (no student names included unless you added them).
☁️ Cloud Sync (GitHub Gist)
Sync your data between devices using a private GitHub Gist — only you can see it. Your token stays saved on this device only and is never included in exports or the Gist itself. Needs a token with gist access (classic token with the "gist" scope, or a fine-grained token with "Gists: read and write").
App Info
App: EduInterp v1.0
Storage: Browser localStorage, plus an optional private GitHub Gist if you turn on Cloud Sync above
Purpose: Personal educational interpreting professional log
No data transmission unless Cloud Sync is turned on and you tap Push/Pull
